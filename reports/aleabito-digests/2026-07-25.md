小白解释：
这条是她整套"瓶颈投资"论点的核心归纳，值得逐层看。①**新增事实**：据 Reuters，Intel 与 AMD 将与中国客户签 AI 数据中心用 CPU 的长期协议（LTA = Long-Term Agreement，长期供货协议）；据消息源，中国部分 CPU 产品年初至今涨价超 40%、个别产品月环比涨超 10%。②**为什么 CPU 也缺**：AI 推理集群里 GPU 并非独立工作，每台 AI 服务器都要配 CPU 做调度与数据预处理（她说的"CPU ratios"即 GPU:CPU 配比），推理需求爆发后 CPU 成为被动跟涨的瓶颈。③**她真正想说的是"结构"而非"某只股"**：她把 CPU 长约放进一张更大的表——内存（MU/三星/SNDK/SK 海力士签 DRAM 与 NAND 长约）、光子学（LITE/COHR 签 EML 激光长约；Trendforce 称 AMD 与超大厂正在追 CW 连续波激光长约），并推测 MLCC 到载板也一样。④**结论句的逻辑**：LTA 通常带 take-or-pay 条款（买方不提货也要付钱），所以当需求以多年期付款义务的形式被锁定，"泡沫破裂"式的需求瞬间消失就更难发生——这是她对"AI 泡沫论"的正面反驳。需要提醒：Reuters 报道为二手转述、条款与规模未披露；40% 与 10% 的涨价来自"消息源"（sources），未经核实、且中国 CPU 市场受出口管制与本地替代影响、涨价原因可能与 AI 需求之外的因素（供给管制、渠道囤货）混合；LTA ≠ take-or-pay，两者她在这里等同处理是**论证上的跳跃**——只有明确含最低提货义务的合同才具备她说的抗周期性质，而多数 LTA 只约定优先供货与价格框架；即便真是 take-or-pay，也只把"需求消失"转成"对手方违约/破产"风险（她上窗自己问过"对手方有没有钱"）；她自持内存与光子学链多只标的、这条正是对其持仓论点的自我辩护，利益相关显著。

第一性原理：
按 5 杠杆拆：①需求 durability——Waymo-Uber 一条落在**分发 vs 供给的价值分配**而非需求总量：Robotaxi 的终端需求（出行）durability 极强，但价值在链条上的归属正在从聚合平台（Uber）向自动驾驶资产方（Waymo）转移；②供给瓶颈——自动驾驶的瓶颈是"通过验证的自动驾驶车队 + 监管许可"，这类瓶颈的持有者（Waymo）天然具备向下游一体化的动机，这是分手传闻的结构性根源；③定价权——一旦 Waymo 自有分发，Uber 在该品类的定价权归零；对 Uber 的对冲只能是多源接入（这正是她说的"中立玩家"路径）；④资本强度——自动驾驶是极重资本 + 长监管周期，Uber 若垂直整合需要承担它一直试图避免的重资产（Uber 当年正是卖掉 ATG 才走轻资产路线，她未提这一段历史包袱）；⑤法治-地缘——Robotaxi 受各州/各城监管牌照约束，是天然的区域性壁垒。价值 vs 叙事：可沉淀锚是"FT 报道 Waymo 探索与 Uber 分手""黄仁勋注册 X 发开源模型公开信""AMD 现场赠送限量周边"；"我去年就说过""Avride 是最优路径""Waymo 是 Uber 最强颠覆者"是她的判断与事后归因；花絮两条不含任何投资信息、但含**影响力与独立性**的信息。
Buffett 直接判断：
护城河：$GOOGL/Waymo 的护城河（数据 + 车队 + 监管许可 + 资本）在本条中被侧面加强；$UBER 的护城河（双边网络效应）在供给方具备直连能力时被结构性削弱——这是 Buffett 会关注的"护城河正在变窄"的典型信号；$NBIS Avride 无任何可量化的护城河证据。
赚钱能力：本条无任何财务数据；Waymo 与 Avride 均未披露单位经济；Uber 的当期盈利不受"探索分手"影响，但终局叙事被改写。
客户替换风险：对 Uber 而言，风险不是客户换平台，而是**供给方绕过平台直连客户**（disintermediation），这比普通替换风险更致命；对 Waymo，分发可自建、替换风险低。
Buffett 式好公司：Uber 的商业模式在这条里暴露了 Buffett 最警惕的结构——利润依赖于"自己不拥有的资产 + 自己不控制的供给"。反过来，这条对 GOOGL 是加分项（在自动驾驶上同时拥有技术、车队与最终分发）。$NBIS Avride 属纯期权、无估值输入。花絮两条在 Buffett 框架下的唯一价值是提醒：信息源的独立性本身就是应当被折价的变量。
